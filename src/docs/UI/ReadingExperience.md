# 文章阅读体验

主要实现：`PostLayout.astro`、`post.css`、`post-standalone.js`、`reading-compass.js/css`、`post-reading-desk.js` 与 `post-annotation.js`。

## 正文与目录

标题、元信息、标签和正文由 Astro 构建输出。桌面正文和目录位于同一网格；手机目录使用实色抽屉，支持关闭按钮、Esc、焦点循环、焦点恢复和选择章节后关闭。切换到桌面宽度时释放手机滚动锁。

Markdown 原有标题 id 保留，章节跳转考虑导航偏移。回顶按钮的可见状态与键盘顺序同步，滚动行为尊重减少动态效果设置。

## 阅读操作

桌面可切换正文默认行宽与 58ch 窄行宽；手机隐藏这项控制。页面没有全文百分比、章节进度刻度或自动恢复滚动位置的接缝提示。

桌面将待读、摘录、拾页入口与行宽控制放在文章目录上方，不在正文前重复占行。1100px 及以下，这组操作回到正文前的一条紧凑工具栏；断点变化时移动同一份 DOM，保留已保存状态与焦点。文章元信息与标签之间使用紧凑间距。

文章列表页以文章为主栏，阅读桌入口、标签和专栏筛选移至桌面右侧。小屏保留阅读桌链接，将筛选按需展开；当前筛选与结果数在列表上方显示，可一键清除。折叠按钮同步 aria-expanded，收起区域使用 inert，避免键盘焦点进入不可见的标签。远端封面失败时收起缩略图区，标题链接继续可用。

文章可加入本地待读。选中文字可进入段落讨论或摘录到阅读工作台；键盘 Tab 可进入出现的选择菜单，Esc 关闭，手机选择也使用相同菜单。私人摘录不等待云端讨论初始化成功。详见[阅读工作台](../页面和功能/拾页阅读工作台.md)。

## 内容展示

- 封面首屏加载，失败时退化为文字标题。
- 代码使用构建期 Shiki 深浅主题；前端复制能力独立于可选高亮 CDN。
- 超宽代码和表格可用键盘进入滚动区；仅在实际溢出时显示横向位置提示。
- 简介按钮支持点击、键盘和 Esc；图像画廊支持触屏与键盘。
- 文章内联引用、文件预览、提示、Mermaid 与脚注见[内联组件](../页面和功能/文章内联组件说明.md)和[脚注说明](../页面和功能/文章脚注与参考文献说明.md)。
- 编辑选择的主题路线会在相关正文后标出当前文章与其他阅读入口。

## 验证

`npm run test:ui:polish` 覆盖文章布局、目录、行宽、代码与横向滚动；`npm run test:ui:desk` 覆盖待读、摘录与导出。云端评论和远端媒体另行验收。
