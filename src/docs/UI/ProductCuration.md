# 页面目录与内容取舍

公开目录根据用途组织，而不是把所有实验文件都列为产品。文章、工具、游戏和实验室保留各自的数据来源与维护边界。

## 目录的真实来源

| 范围 | 配置 |
| --- | --- |
| 工具 | `assets/pages/tool/tool.json` |
| 游戏 | `assets/pages/games/game.json` |
| 实验室 | `assets/pages/a/projects.json`，以实验室页面的筛选结果为准 |
| 功能导航 | `assets/pages/blog/functions.json` |
| 下线兼容 | `src/config/retired-pages.json` |

条目名称和说明应对应可打开的页面与真实能力。重复入口可以作为导航捷径，但不能被统计成多个独立产品；管理员页面按管理用途保留，不作为普通访客的公共产品宣传。

## 取舍原则

保留可以解决实际任务的工具、个人原创内容、校园内容和有完整流程的互动体验。纯演示、重复、失效或容易误导的页面可以下线，但要检查页面代码、资源、目录、站内搜索、sitemap 和旧链接。

下线路由由配置生成 noindex 跳转，保留旧地址的可恢复性。源代码与素材的历史由 Git 保存，不为每次删除在源码中维护一份副本。

文章审核应逐篇阅读，考虑原创观点、独有数据、可复现实验、事实准确性与重复程度。不能仅按篇幅、题材或访问量批量删除。未完成的审核与集成验收记录在[待办](../dev/待办.md)，不在当前能力介绍中承诺已经完成。
