# 目录与工具页面规范

工具、游戏、实验室、功能导航共用 `src/layouts/CatalogLayout.astro`。数据仍从原 JSON 读取，内容在 Astro 构建时输出，不等待浏览器请求或重绘。目录内容与筛选行为共用布局和增强脚本。

## 用户任务

先了解页面用途，再通过名称/用途搜索、分类筛选找到入口。目录按 ProductCuration.md 保留精选条目与目的地址，站内链接在当前标签页打开，外站明确标记。搜索和分类可以组合，状态写入 URL；空结果可一键清除。

搜索时各分类的数字同步显示关键词匹配数，搜索框可直接清空。卡片与紧凑列表共用原始链接，布局偏好保存在本地。收藏按钮与入口链接互为兄弟元素，不嵌套交互控件；列表模式仍保留说明、外站标记和收藏操作。

## 随行架

四个目录与首页共用 `PocketShelf.astro`。可收藏最多 8 个站内入口，另保留从目录或随行架最近打开的 8 项。记录包含中键打开；只保留路径，不存访问时间、账号或设备标识。最近记录可单独清除，收藏不受影响。首次访问时显示轻量提示，首页没有记录时不占位。

- `src/utils/pocket-catalog.ts` 从既有目录 JSON 派生白名单、名称和分区，重复路径合并，不维护另一份入口数据。
- `assets/js/pocket-store.mjs` 定义 `quark.pocket.v1` 的读取和变更；存储内容为 `{version:1,pins:[],recent:[],view:'grid'|'list'}`。
- `pocket.js` 负责界面和跨标签页更新。写入前重读存储，损坏数据或存储不可用时提示失败，不覆盖原数据。动态名称通过 DOM 文本属性输出。
- 页面无 JavaScript 时隐藏随行架与收藏按钮，构建输出的目录链接继续可用。
- 收藏不是云端同步；清理浏览器数据会清除随行架。阅读清单与摘录继续由拾页独立管理。

1000px 及以下，随行架收进搜索框旁的原生 details 控件，展开为锚定面板，不推移下方卡片。支持 Esc、点击外部关闭、焦点恢复和响应式切换。存储或容量错误会自动展开反馈；正常收藏不弹出面板。桌面侧栏随滚动保持可用，并在视口不足时内部滚动。

模型测试见 `tests/pocket.test.mjs`，浏览器回归见 `tests/ui/decision-pocket.cjs`。

## 视觉规则

- 使用实色背景、清晰文本、留白与细分隔线。内容卡片只保留一层边框，卡片内部不再嵌套卡片。
- 单张卡片呈现名称与用途，最多两枚有意义的标签。分类信息在区块标题与侧栏显示，不重复占据每张卡片。
- 桌面为内容主栏加搜索、布局切换与随行架右侧栏；分类位于卡片上方。宽屏三列，中等屏宽两列，手机单列。未填满的一行左对齐，卡片不随数量变形。
- 游戏使用 `GameCover.astro` 的内联图形，不加载整张游戏截图或远程封面。
- 阅读字体由 user-preferences.js 统一应用，默认霞鹜文楷；保留用户保存的字体选择。默认普通光标，粒子效果为可选项。
- 导航和内容均使用实色表面，不依赖 backdrop-filter。

## 交互与性能

- 目录链接在 JavaScript 禁用时仍可使用；搜索控件仅在增强脚本可用时显示。
- 搜索有可读标签、键盘快捷键和结果提示；保留清晰的键盘焦点。
- `/assets/css/feature-pages.css` 通过 `feature-page` 和具体页面类名约束样式，避免覆盖其他全屏应用。
- 工具表单优先展示输入、主操作与结果。减少重复框线、整屏动画和不必要的自动聚焦。
- 游戏画布缩放后，命中检测必须使用 CSS 尺寸与内部画布尺寸的比例换算。
- 不把搜索、计时器、棋盘数据提交到后端做 UI 测试；联网服务另行做有凭据的集成验证。
