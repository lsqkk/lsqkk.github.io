# 目录与工具页面规范

工具、游戏、实验室、功能导航共用 `src/layouts/CatalogLayout.astro`。数据仍从原 JSON 读取，内容在 Astro 构建时输出，不等待浏览器请求或重绘。目录内容与筛选行为共用布局和增强脚本。

## 用户任务

先了解页面用途，再通过名称/用途搜索、分类筛选找到入口。目录按 ProductCuration.md 保留精选条目与目的地址，站内链接在当前标签页打开，外站明确标记。搜索和分类可以组合，状态写入 URL；空结果可一键清除。

## 视觉规则

- 使用实色背景、清晰文本、留白与细分隔线。内容卡片只保留一层边框，卡片内部不再嵌套卡片。
- 单张卡片呈现名称与用途，最多两枚有意义的标签。分类信息在区块标题与侧栏显示，不重复占据每张卡片。
- 桌面为分类侧栏加三列内容；平板为两列，手机为单列。未填满的一行左对齐，卡片不随数量变形。
- 游戏使用 `GameCover.astro` 的内联图形，不加载整张游戏截图或远程封面。
- 阅读字体由 user-preferences.js 统一应用，默认霞鹜文楷；保留用户保存的字体选择。默认普通光标，粒子效果为可选项。
- 导航和内容均使用实色表面，不依赖 backdrop-filter。

## 交互与性能

- 目录链接在 JavaScript 禁用时仍可使用；搜索控件仅在增强脚本可用时显示。
- 搜索有可读标签、键盘快捷键和结果提示；保留清晰的键盘焦点。
- `/assets/css/feature-pages.css` 通过 `feature-page` 和具体页面类名约束样式，避免覆盖其他全屏应用。
- 工具表单优先展示输入、主操作与结果。减少重复框线、整屏动画和不必要的自动聚焦。
- 游戏画布缩放后，命中检测必须使用 CSS 尺寸与内部画布尺寸的比例换算。
- 不把搜索、计时器、棋盘数据提交到后端做 UI 测试；联网服务另行做有凭据的集成验证。

科学计算器、番茄钟、参考文献、OCR、语音转文字、图片 Emoji、找不同、聊天词云、随机转盘、图片混淆、打字训练、思政题库，以及校园图寻与联机游戏入口。

回归脚本见 `tests/ui/site-smoke.cjs`；包含目录无 JS 降级、筛选、计算器、计时器、旧入口跳转、精选目录完整性，以及浅深主题和 390/768/1440 像素宽度检查。
