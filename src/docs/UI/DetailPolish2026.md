## 五处组合设计

这些设计围绕本站真实内容制作，不宣称全网独创。

### 1. 章节刻度尺

文章正文前用一排细刻度代替大进度条。每格对应一级章节，显示各章节已读范围；当前章节有描边，同时展示章节编号、名称和全文进度。每格可点击、键盘聚焦，有完整名称；文章没有章节时仅显示正文进度。

### 2. 阅读接缝

在同一标签页离开长文后，再访问时出现一条细竖线和“接着读 · 章节名”。用户主动点击才恢复到章节；不接管浏览器原本的滚动恢复，也不覆盖显式 hash。可忽略，读完清除，仅使用 sessionStorage，不请求服务器。

### 3. 可变行宽

桌面端可以在默认正文宽度与 58ch 行宽之间切换。只收窄正文，保留标题与目录的位置；当前视口不因工具栏高度变化而跳动。手机隐藏这项冗余控制。

### 4. 更新线谱

首页更新列表把“类型、内容、日期”组织成两列三元素：固定紧凑的类型标记，弹性换行的内容，沿内容边线排列的日期。窄屏也不会出现类型徽章独占一整行，长更新可以直接读完。

### 5. 横向内容路标

只在代码或表格真实超宽时显示一条细线和方向提示。滚动到中间显示双向提示，到右端改为“已到右端”；线条同步记录横向位置。窄内容完全不显示，避免每个代码块都增加操作噪声。
