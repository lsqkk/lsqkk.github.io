# 加载、空结果与失败状态

确定性内容优先在构建期输出，不先清空再等待浏览器重建。骨架屏只用于尚未取得的异步内容。

## 内容来源与处理

| 内容 | 处理方式 |
| --- | --- |
| 首页文章、动态、更新说明 | 构建期输出；可选在线统计和互动再增强 |
| 工具、游戏、实验室、功能导航目录 | `CatalogLayout.astro` 输出入口；搜索和分类由脚本增强 |
| 文章标题、正文、标签 | Astro 内容集合直接输出 |
| 留言、云端互动、用户资料 | 按请求显示有限的加载状态，成功后替换，失败时说明并提供可行出口 |
| 图片与文件预览 | 预留尺寸；加载后结束占位，失败时给出降级状态 |
| 本地清单和摘录 | 读取本地数据；空状态说明如何开始，保存失败时明确反馈 |

目录不是浏览器 fetch 到 JSON 后才出现的内容，不应重新引入旧目录脚本或整页骨架。

## 实现约定

1. 首屏可以确定的内容直接输出可用 HTML。
2. 异步区在请求前提供与最终尺寸接近的轻量占位，避免布局跳变。
3. 请求成功、空数据、超时、失败各自处理；不要永久显示“加载中”。
4. 使用 `role="status"` 或适当的 `aria-live` 播报结果；无关的状态不抢焦点。
5. 图片错误后结束骨架效果，避免同时显示破图和持续扫描背景。
6. `prefers-reduced-motion` 和站内减少动态效果下使用静态占位。

共享样式来自 `tokens.css` 及各页面的前缀规则。颜色依赖 `--surface*`、`--line*`，不为骨架重新定义一套主题。

验证时同时模拟成功、空结果和外部请求失败；屏蔽网络的测试只证明降级和本地功能，不代表真实在线服务已验收。
