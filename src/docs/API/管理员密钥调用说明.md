# 管理员登录与会话

处理器为 `api/admin.js`，来源设置在 `api/_cors.js`。两个动作均使用 POST：

| 路由 | 请求体 | 主要响应 |
| --- | --- | --- |
| `/api/admin?action=auth` | `{passwordHash}` | `success`、`token`、`expiresAt` |
| `/api/admin?action=verify` | `{token}` | `valid`、`expiresAt` |

服务端需要 `ADMIN_PASSWORD_HASH`（SHA-256 哈希）和 `ADMIN_SESSION_SECRET`。当前会话有效期为两小时，签名和过期校验在同一处理器内实现。

~~~js
const response = await fetch('__API_BASE__/api/admin?action=auth', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({passwordHash})
});
const result = await response.json();
if (!response.ok || !result.success) throw new Error('管理员验证失败');
~~~

会话验证向 `/api/admin?action=verify` 发送 `{token}`。调用方检查 HTTP 状态和 `valid`，退出时清理本地会话。前端提交哈希不等于无需保护凭据，仍使用 HTTPS，并按实际页面维护 token。

此接口不自动给所有其他 API 添加管理员授权；实际操作需要核对对应处理器的权限逻辑。
