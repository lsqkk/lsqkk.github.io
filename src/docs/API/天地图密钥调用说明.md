# 天地图客户端配置

地图页通过 `__API_BASE__/api/keys?names=tianditu` 获取客户端配置脚本，脚本设置 `window.TIANDITU_KEY`。服务端环境变量为 `TIANDITU_KEY`，来源设置集中在 `api/_cors.js`。

~~~html
<script src="__API_BASE__/api/keys?names=tianditu"></script>
~~~

地图初始化前检查配置是否存在，并向用户显示可读的未配置或加载失败提示。图层 URL 模板位于 `assets/pages/a/map/map.js`。

该 key 要交给浏览器请求地图，不能通过动态脚本注入来保密。按提供方要求配置适用的域名、配额和权限。配置变化后核对生产页面请求，而不只检查接口返回了 200。
