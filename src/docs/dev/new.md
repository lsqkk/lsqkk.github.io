- [x] 「谍报风云」聊天室 / 选队 / 掉线移出 / 去抖动 / 音效
完成时间：2026-10-15
完成说明：
  1. **房间聊天室**：右下角常驻圆形入口，点开是浮层面板（刻意不用原生 `<dialog>`，避免 top layer 盖住站点自定义光标）。面板内有「房间」（4 人可见）与「X 队」（只队友可见）两个频道，未读红点、提示音、700ms 发送限流、可折叠的聊天注意事项。
     - 聊天数据挂在 `spy-signal/chats/{房间码}`，是**房间节点的兄弟路径**：放进房间节点的话，① `normalizeRoom()`→`commit()` 的字段展开会在每次对局动作时把聊天记录整个抹掉，② 房间 `on("value")` 监听会让每条聊天消息都触发一次整屏重绘。房间释放时连带删除聊天。
     - 「只队内可见」用**两条独立路径**（`.../teams/{A|B}`）实现，而不是单列表加频道字段过滤：客户端只订阅自己队伍的节点，对方队伍的消息不会进入内存，也就在结构上不可能被渲染出去（与 `visibleWords()` 同一思路）。
  2. **加入时选队伍**：加入对话框新增「自动 / A 队 / B 队」（`JOIN` 载荷的 `team`，目标队满员则回退到人少的一队）；大厅里自己那行可「换到 X 队」（`SWITCH_TEAM`），换队会清掉准备状态与角色槽。重连仍保持原座位。
  3. **掉线移出**：`bindPresence` 断线时一并写 `offlineAt`（服务端时间），界面在大厅/准备阶段显示 `离线 1:23 后移出`（每秒只改文本节点，不重绘）；房主可手动移出离线玩家，离线超 2 分钟由**任何在场玩家**代发一次自动移出（否则房主掉线后没人能挪走他）；被移出者看到 `meta.lastKick` 的原因。顺带修掉既有 bug：**房主退出后 `meta.hostId` 指向已离开的人，剩下的人谁也点不动「开始游戏」** —— 现在会自动把房主交给最早进房的剩余玩家。另修复 `bindPresence` 直写 `players/{uid}` 可能造出"幽灵座位"占位的问题（`normalizeRoom` 忽略没有 `joinedAt` 的记录）。
  4. **消除整屏抖动**：根因是"整屏 clear + 重建"叠加 `.ss-block`（60 多处）上的 `animation: ss-rise` —— 任何状态变化都会让满屏的块同时重播淡入上移。已删除该动画（连同 `ss-winner` 的与 `@keyframes ss-rise`）、收窄并放慢 `ss-pulse`，另外新增"房间无变化就跳过重绘"、渲染前后保留滚动位置、聊天消息只重画聊天面板（不碰 `#ssScreens`）。
  5. **音效**：新增 `sound.js`，用 WebAudio 振荡器**现场合成、不引入音频文件**（仓库无可复用音效资源，其它游戏的 `.mp3` 引用多数已失效），覆盖新消息 / 进出房 / 开局 / 轮到我出手 / 本轮结算 / 作废 / 胜负 / 被移出；顶栏常驻 🔊 开关并持久化。
  6. 顶栏连接状态改为「状态点 + 文字」、窄屏只留状态点（新增音效按钮后 390px 宽度会把「谍报风云」「退出」挤成竖排）。
  测试：单测 53 → 89 项（新增选队 / 换队 / 移出 / 房主转移 / `offlineAt` 往返 / 超时移出的 reducer 门禁 / 空壳房间 / 聊天文本清洗与码点截断）；新增浏览器冒烟 `private/spy-signal-e2e/chat-smoke.mjs`（43 项，含"对手队伍的私聊不出现在 DOM 里""聊天写入不重建对局屏""`.ss-block` 没有进场动画""离线超时被自动移出""被移出的人回到入口屏"）。假 RTDB 抽成 `private/spy-signal-e2e/fake-rtdb.mjs` 与截图走查共用。详见 `src/docs/页面和功能/谍报风云.md` §12–§15。
  7. **代码审查后的加固**（自发修复，非新需求）：
     - 「离线满 2 分钟」这条规则从"只在界面巡检里判断"改成**由 reducer 兜底**（必须有 `offlineAt` 且确实过点了），避免客户端时钟偏差把刚掉线的人提前移出；同时订阅 `.info/serverTimeOffset` 导出 `serverNow()`，巡检 / 倒计时 / reducer 统一用服务器时钟。
     - 修掉一个会**永久占用房间码**的坑：`bindPresence` 是直写 `players/{uid}` 的，房间若在某人离线期间被删掉，他重连时这一写会把房间节点整个重建出来，得到只有 `players`、没有 `meta` 的**空壳房间**，命中不了任何 TTL。现在 `roomRelease()` 把无 `createdAt` 的节点直接判可释放、数人时只数带 `joinedAt` 的座位，`applyAction()` 把无 `meta` 的节点当作不存在（不接受 JOIN，但可被 CREATE_ROOM 重新占用）。
     - `sanitizeText()`（昵称 / 暗号 / 笔记 / 聊天共用）改为**按码点截断**：原先 `slice()` 按 UTF-16 单元数，emoji 卡在边界上会被劈成半个字符、渲染成乱码。
     - `reduceSwitchTeam` 改为复用 `clearRoles()`（原先自己手写清角色槽，只清了自己的 `role` 而去掉 `clearRoles` 那条"人人 tag 都清掉"的不变量）。
     - 修掉 `main.js` 里一个**既有的 NUL 字节**（`let renderedModal = "\0"`，早先某次编辑把空格写成了 0x00），它让各种工具把该文件当成二进制；顺手改成正常哨兵字符串并补注释说明初值用意。

- [x] 「谍报风云」修复：博客头像不显示 / 弹窗挡住光标
完成时间：2026-10-15
完成说明：
  1. **博客头像不显示**：`avatar()` 部件只认房间玩家对象的字段名（`avatarType`/`avatarColor`/`avatarUrl`），
     而 `sanitizeAvatar()` 返回的是 `type`/`color`/`url`，字段名对不上就静默退化成了首字圆圈。
     现已让该部件同时接受两种形状。
  2. **头像地址规则过严**：原先只放行四个白名单域名，把用户自己在站点里设置的头像（图床地址）也挡掉了。
     现改为与站点评论头像一致——https + 常见图片后缀（jpg/jpeg/png/webp）即可，另额外放行 GitHub 这类无后缀来源。
  3. **身份偏好被错误固化**：原先每次存档都会写入当前身份模式，于是"当时没登录算出的 manual"
     被当成用户的明确选择永久保留，登录后也读不到博客身份。现改为只在用户显式点"改用…"时才记录（新键 `spySignalIdentityPref`）。
  4. **弹窗挡住自定义光标**：`cursor-trail.js` 注入了 `* { cursor: none !important }` 并用
     `z-index:9999` 的元素当光标，而原生 `<dialog>` 在 top layer、层级高于任何 z-index，
     于是光标被盖住、真实光标又是 none，整屏看不见指针只能盲点。现于弹窗打开期间给 body 加
     `ss-modal-open` 恢复原生光标。该坑已记入 CLAUDE.md 供后续页面参考。
  5. 身份变化改为无需刷新即时生效：新增 `storage`（跨标签页登录）与 `visibilitychange`（从登录页切回）监听。
  新增身份识别走查脚本，覆盖各种登录形态并直接断言渲染后的 `background-image`。
