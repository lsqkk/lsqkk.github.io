# 夸克闪传

入口为 `/a/share/`，提供在线发文件、在线收集和加密离线包三种操作。参考文叔叔的取件链接与文件收集体验。 [文叔叔产品说明](https://www.wenshushu.cn/about) [文叔叔帮助中心](https://www.wenshushu.cn/help)

## 在线直传与收集

1. 发送方选择文件、文件夹或添加附言，生成连接码或二维码。收集方也可以先生成邀请，由加入的人选文件。
2. 对方打开邀请，在页面确认连接。八位连接码在创建后 15 分钟内可加入一次，既可输入，也可从分享链接读取。旧版三字母码仍可加入旧发送端正在等待的房间。
3. 接收方检查文件清单、确认后开始传输。发送端收到接收回执后才显示成功。接收端可预览常用图像、音视频和纯文本，也可逐个下载或保留目录结构打包为 ZIP。

每批最多 500 个文件、512 MiB，接收端临时在内存中持有文件，关闭或刷新后请重新接收。连接依赖 WebRTC 和 STUN，严格 NAT 或企业防火墙可能阻止直连。可改用同一 Wi-Fi 或使用离线包。房间匹配后可以继续收发多批文件，信令房间到期后已连接的数据通道仍可用。

## 加密离线包

验证登录后可创建 1、6 或 24 小时有效的离线取件链接。单包上限 25 MiB，包含目录清单、附言、原始文件和少量加密开销。浏览器使用独立的随机 AES-256-GCM 密钥加密文件名、内容和附言，密钥放在链接的 `#` 片段中。接收方无需登录，浏览器下载密文后在本地解密。复制时请保留完整链接，收到链接的任何人都可以取件。

每账号每天 10 包，全站每天 80 包，按北京时间零点刷新，签发上传凭证即计入额度。创建者可在本机用同一账号撤回有效的离线包，撤回后服务停止签发下载凭证。已签发的下载凭证最长剩余 90 秒，已经下载的副本仍由收件人持有。本机保留最近 12 条传输的时间、数量和大小，以及用于撤回的有效包编号、过期时间和服务端签发的匿名账号标识。文件名、附言、密钥和取件链接不写入本机记录。

## 部署

- API 使用 Vercel 项目的 `/api/share`，只接收站点白名单来源的 JSON POST 请求。`status` 返回离线功能配置状态，`room-*` 和 `legacy-*` 处理信令，`drop-*` 处理离线包登记、签名和撤回。前端从 `src/config/json/api.json` 读取现有 API 基址。
- 在线直传使用原有 `FIREBASE_SERVICE_ACCOUNT` 或 `FIREBASE_SERVICE_ACCOUNT_JSON` 及 `FIREBASE_DATABASE_URL`。确保 Firebase 规则只允许 Admin SDK 访问 `quark_share_rooms_v2`、`quark_share_room_quota`、`quark_share_drops`、`quark_share_drop_quota`，不要通过通用数据库代理公开这些路径。旧版连接兼容读取原 `rooms` 节点。
- 为离线包设置独立私有桶 `R2_SHARE_BUCKET`，保持 `r2.dev` 与自定义公共访问关闭。该桶使用 `R2_ENDPOINT`，`R2_ACCESS_KEY_ID` 和 `R2_SECRET_ACCESS_KEY` 对该桶需要对象读写权限。未配置私有桶时，离线页会提示暂不可用，在线信令使用同一 API 的 Firebase 部分。
- 私有桶 CORS 为站点域名允许 `PUT`、`GET`，`AllowedHeaders` 包括 `Content-Type`、`Cache-Control`、`If-None-Match`。部署时验证浏览器发送的 `Content-Length` 和签名值匹配。对 `share-drop/` 前缀设置 2 天对象生命周期，清理过期、撤回和未完成登记的密文。 [R2 跨域配置](https://developers.cloudflare.com/r2/buckets/cors/) [R2 生命周期](https://developers.cloudflare.com/r2/buckets/object-lifecycles/)
- 使用生产域名分别打开两个窗口，确认生成连接码、收集邀请、拒绝、接收回执和 ZIP。登录后上传一个小文件并在无痕窗口取件，随后撤回链接并再次访问。部署前本地可运行 `node --test tests/share.test.mjs`，对预览服务运行 `node tests/ui/share.cjs`。浏览器测试使用真实本地 WebRTC，信令与对象存储由测试模拟。
