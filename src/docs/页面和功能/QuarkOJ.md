# QuarkOJ

QuarkOJ 位于 `/a/oj`，无需登录即可练习。总览显示六个专题题单、练习进度和最近提交。题库可按题号、标题、难度、专题和练习状态组合筛选，筛选条件保存在 URL 中。练习页支持样例自测、自定义标准输入和逐用例评测。

## 数据与评测

- 题面和评测用例在 `assets/pages/a/oj/problems`。历史索引中的重复题号由题库加载器合并。用例作为静态资源公开，评测结果适用于个人练习。
- 浏览器把源代码和输入发送给 Judge0 CE。Python 和 Node.js 在题目基准 CPU 时限上增加 2 秒，以覆盖解释器启动成本。Java 和 Node.js 使用更大的虚拟地址空间，成功执行后再按 Judge0 报告的内存用量判定是否超限。
- 草稿按题号和语言保存，收藏与提交历史也保存在当前浏览器。旧版每题一条的记录仍可查看和恢复。曾经通过的题目在后续提交失败后仍计入已通过。
- 停止等待会取消浏览器的后续请求。已经送达 Judge0 的任务可能继续执行。讨论区继续使用站点现有的讨论数据和管理员入口。

## 验证

运行 `npm run sync:public` 和 `npm run dev`，再运行 `node tests/ui/quark-oj.cjs`。测试在浏览器中模拟 Judge0 响应，覆盖选题、收藏、旧记录、草稿恢复、样例自测、多用例评测、异常恢复、提交复盘和窄屏布局。
