# QuarkOJ

QuarkOJ 位于 `/a/oj`，无需登录即可练习。总览显示专题题单、练习进度和最近提交。题库可按题号、标题、知识点、难度、专题和练习状态组合筛选，筛选条件保存在 URL 中。练习页支持样例自测、自定义标准输入和逐用例评测。

`/a/oj/cs61b` 将 UC Berkeley 的项目、作业及实验官网入口与可在线评测的改编和变体分开呈现，并按课程顺序显示各阶段进度。站内课程题采用标准输入输出，优先推荐 Java 17，也可使用其他支持的语言。

## 数据与评测

- 题面和评测用例在 `assets/pages/a/oj/problems`，按历史、通用和 CS61B 分设索引。历史索引中的重复题号由题库加载器合并。洛谷、力扣等题目只作为公开参考入口，站内新增题面和用例独立编写。用例作为静态资源公开，评测结果适用于个人练习。
- 浏览器把源代码和输入发送给 Judge0 CE。Python 和 Node.js 在题目基准 CPU 时限上增加 2 秒，以覆盖解释器启动成本。Java 和 Node.js 使用更大的虚拟地址空间，成功执行后再按 Judge0 报告的内存用量判定是否超限。
- 草稿按题号、语言和账号身份留在当前浏览器，收藏也保存在本机。游客提交本地保存；使用 GitHub 或邮箱验证码登录后，新提交自动同步，可在提交记录页主动导入游客记录。旧版每题一条的记录仍可查看和恢复。曾经通过的题目在后续提交失败后仍计入已通过。
- 停止等待会取消浏览器的后续请求。已经送达 Judge0 的任务可能继续执行。讨论区继续使用站点现有的讨论数据和管理员入口。
- 账号同步后，有完整通过记录的用户可以在练习页发布、更新或撤回题解。发布前可选择通过的提交并检查要公开的源码；服务器从该账号的提交记录附上源码。题解基于练习记录，评测仍由浏览器发起，不适合作为比赛或证书的通过凭证。

## QuarkBot 助教

在练习页打开 QuarkBot，可以询问提示、算法与复杂度、边界情况或完整代码。默认附带公开题面和样例；只有主动勾选时才会把当前编辑器的前 6000 个字符发给所选模型，使用这段代码得出的回复不保存到会话记录。AI 回复里有代码块时，可以手动确认填入编辑器，再自测或提交。

## 验证

运行 `npm run test:oj` 检查题库可重复生成、课程覆盖和账号接口权限。运行 `npm run sync:public` 和 `npm run dev` 后执行 `npm run test:ui:oj`。浏览器测试模拟 Judge0、QuarkBot 和账号 API，覆盖收藏、旧记录、云端源码恢复、评测、题解发布、助教和窄屏布局。
